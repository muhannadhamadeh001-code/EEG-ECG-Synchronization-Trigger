## System Overview

The EEG–ECG synchronization trigger provides a simple and reliable method to establish a shared time reference between independent EEG and ECG recording systems.
The trigger is generated by a microcontroller and transmitted through an opto-isolated digital output. Electrical isolation ensures that no ground loops or noise are introduced into sensitive biosignal acquisition hardware.
The system does not control recording start times. Instead, it provides a precise marker that can be used to align data streams during offline analysis.
