# Gerber Files

This directory will contain the manufacturing (Gerber) files for the EEG–ECG Synchronization Trigger PCB.

## Why Gerbers Are Not Included Yet

At this stage, the PCB is currently being manufactured and has not yet completed electrical validation.  
To avoid publishing manufacturing outputs that may not correspond to a tested and verified hardware revision, Gerber files are intentionally withheld until validation is complete.

## Planned Release

Once the assembled board has been powered, programmed, and validated:
- Gerber files will be added under a versioned subfolder
- The release will be tagged accordingly
- Validation notes will be included

## Current Status
- PCB design completed
- Manufacturing in progress (JLCPCB)
- Assembly and validation pending
